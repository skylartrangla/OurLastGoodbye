# Our Last Goodbye

A private, romantic five-day Hanoi journey with:

- five daily timelines;
- flexible checkpoints and nightly treasure rewards;
- a freestyle Hanoi activity picker;
- Plan B replacements when plans change;
- locally saved progress; and
- a final letter unlocked after all five treasures.

## Local development

```bash
npm install
npm run dev
```

## GitHub Pages

Every push to `main` runs the included GitHub Actions workflow and publishes the
static site through GitHub Pages.
